# pospos247

ระบบ POS หน้าร้าน เปิดผ่านเบราว์เซอร์ได้ทันที ไม่ต้องใช้ Apps Script หรือเซิร์ฟเวอร์ ข้อมูลทั้งหมดเก็บอยู่ในเครื่องที่ใช้ขาย

| หน้า | ลิงก์ |
|---|---|
| หน้าหลัก | https://alekryker.github.io/pospos/ |
| ทดลองเล่น (ข้อมูลแยกจากของจริง, PIN แอดมิน `1234`) | https://alekryker.github.io/pospos/?demo=1 |
| ระบบเดิม (ใช้ Apps Script) | https://alekryker.github.io/pospos/legacy/ |

## เริ่มใช้งานครั้งแรก
1. เปิดหน้าหลัก แล้วตั้งชื่อร้าน ชื่อแอดมิน และ PIN
2. นำเข้าสินค้า: กด **ดึงสินค้าจากระบบเดิม** (ดึงครั้งเดียว) หรือ **นำเข้าจากไฟล์ CSV** (ใน Google Sheet ไปที่ ไฟล์ → ดาวน์โหลด → CSV)
3. ตั้งค่า → แจ้งเตือน Telegram: ใส่ Bot Token และ Chat ID แล้วกด "ส่งข้อความทดสอบ"
4. ตั้งค่า → พนักงาน: เพิ่มแคชเชียร์ และตั้ง PIN ให้แต่ละคน
5. เปิดกะ แล้วเริ่มขายได้เลย

## ข้อมูลเก็บที่ไหน
- สินค้า พนักงาน บิล กะ และการตั้งค่า เก็บในเบราว์เซอร์ของเครื่องที่ใช้ขาย
- เครื่องอื่นจะไม่เห็นข้อมูลชุดนี้ ถ้าจะย้ายเครื่อง ให้กด "สำรองข้อมูล" แล้วนำไฟล์ไป "กู้คืน" ที่เครื่องใหม่
- **ควรสำรองข้อมูลเป็นประจำ** (ตั้งค่า → ข้อมูล → สำรองข้อมูลทั้งหมด) เพราะถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลในเครื่องจะหายไปด้วย
- Token ของ Telegram อยู่ในเครื่องนั้นเท่านั้น ไม่ได้อยู่ใน GitHub และไม่ถูกรวมในไฟล์สำรอง

## ความสามารถ
- ขาย: ค้นหาสินค้า เลือกหมวด ใส่ส่วนลด (บาท / %) พักบิล รับชำระ 4 แบบ (เงินสด QR โอน บัตร) แสดงเงินทอน
- กะ: เปิดกะ ปิดกะ นับเงิน และสรุปเงินขาด/เกิน
- บิล: ดูย้อนหลังรายวัน พิมพ์ซ้ำ ยกเลิกบิล (คืนสต๊อกอัตโนมัติ)
- รายงาน: รายวัน รายสัปดาห์ รายเดือน ยอดแยกตามวิธีชำระ สินค้าขายดี กำไรขั้นต้น
- Telegram: แจ้งเมื่อขาย ยกเลิกบิล ปิดกะ และสต๊อกใกล้หมด ถ้าเน็ตหลุด ข้อความจะเข้าคิวรอ แล้วส่งให้เองเมื่อกลับมาออนไลน์
- ธีมสว่าง / มืด / อัตโนมัติ

## เครื่องพิมพ์
| วิธี | ใช้กับ |
|---|---|
| Bluetooth | Chrome บน Android และคอมพิวเตอร์ (เครื่องพิมพ์ความร้อนแบบ BLE) |
| สาย USB | Chrome บน Android (สาย OTG) และคอมพิวเตอร์ |
| QZ Tray | Windows / Mac (ต้องติดตั้งโปรแกรม QZ Tray) |
| หน้าต่างพิมพ์ | ทุกเครื่อง รวมถึง iPhone (AirPrint) |

- พิมพ์ภาษาไทยได้ครบ เพราะใบเสร็จส่งไปเครื่องพิมพ์เป็นภาพ
- รองรับกระดาษ 58 และ 80 มม.
- สั่งเปิดลิ้นชักเงินได้ เมื่อใช้ Bluetooth, USB หรือ QZ Tray
