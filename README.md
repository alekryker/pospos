# pospos247

ระบบ POS หน้าร้าน ใช้ฐานข้อมูลชุดเดียวบน Supabase ทุกเครื่องเห็นสินค้า สต๊อก บิล กะ และพนักงานชุดเดียวกันแบบเรียลไทม์ ถ้าเน็ตหลุดก็ขายต่อได้ บิลจะเข้าคิวไว้ แล้วส่งขึ้นฐานข้อมูลเองเมื่อออนไลน์

| หน้า | ลิงก์ |
|---|---|
| หน้าหลัก | https://alekryker.github.io/pospos/ |
| ทดลองเล่น (ไม่ต่อฐานข้อมูล, PIN แอดมิน `1234`) | https://alekryker.github.io/pospos/?demo=1 |
| แอป Android (APK) | https://github.com/alekryker/pospos/releases/latest/download/POS.apk |

## ตั้งค่าฐานข้อมูล (ทำครั้งเดียว)
1. สร้างโปรเจกต์ที่ https://supabase.com (Region: Singapore)
2. SQL Editor → New query → วางไฟล์ [`supabase/schema.sql`](supabase/schema.sql) → Run
3. Authentication → Users → Add user → ใส่อีเมลและรหัสผ่านของร้าน (ติ๊ก Auto Confirm)
4. ใส่ Project URL และ anon key ไว้ที่ `SB_URL` / `SB_KEY` ใน `index.html` เครื่องใหม่จะได้ไม่ต้องกรอกเอง

## เปิดใช้บนเครื่องใหม่
เปิดลิงก์หน้าหลัก แล้วล็อกอินด้วยอีเมลร้าน **ครั้งเดียวต่อเครื่อง** หลังจากนั้นพนักงานแค่เลือกชื่อและกด PIN

## ข้อมูลอะไรอยู่ที่ไหน
- **ใช้ร่วมทุกเครื่อง (อยู่บน Supabase):** สินค้า สต๊อก พนักงาน บิล กะ ชื่อร้าน ใบเสร็จ พร้อมเพย์ และ Telegram
- **เฉพาะเครื่อง:** เครื่องพิมพ์ ขนาดกระดาษ ธีม บิลที่พักไว้ และรหัสเครื่อง (ใช้ขึ้นต้นเลขบิล)
- **Telegram:** ฐานข้อมูลเป็นฝั่งส่งข้อความ Token เก็บอยู่ในฐานข้อมูล หน้าเว็บอ่านกลับไม่ได้

## ความสามารถ
- ขาย: ค้นหาสินค้า เลือกหมวด ใส่ส่วนลด (บาท / %) พักบิล รับชำระ 4 แบบ (เงินสด QR โอน บัตร) แสดงเงินทอน
- กะ: เปิดกะ ปิดกะ นับเงิน และสรุปเงินขาด/เกิน
- บิล: ดูย้อนหลังรายวัน พิมพ์ซ้ำ ยกเลิกบิล (คืนสต๊อกอัตโนมัติ)
- รายงาน: รายวัน รายสัปดาห์ รายเดือน ยอดแยกตามวิธีชำระ สินค้าขายดี กำไรขั้นต้น
- Telegram: แจ้งเมื่อขาย ยกเลิกบิล ปิดกะ และสต๊อกใกล้หมด ถ้าเน็ตหลุด ข้อความจะเข้าคิวรอ แล้วส่งให้เองเมื่อกลับมาออนไลน์
- ธีมสว่าง / มืด / อัตโนมัติ

## เครื่องพิมพ์
| วิธี | ใช้กับ |
|---|---|
| Bluetooth | Chrome บน Android และคอมพิวเตอร์ (เครื่องพิมพ์ความร้อนแบบ BLE) |
| สาย USB | Chrome บน Android (สาย OTG) และคอมพิวเตอร์ |
| QZ Tray | Windows / Mac (ต้องติดตั้งโปรแกรม QZ Tray) |
| หน้าต่างพิมพ์ | ทุกเครื่อง รวมถึง iPhone (AirPrint) |

- พิมพ์ภาษาไทยได้ครบ เพราะใบเสร็จส่งไปเครื่องพิมพ์เป็นภาพ
- รองรับกระดาษ 58 และ 80 มม.
- สั่งเปิดลิ้นชักเงินได้ เมื่อใช้ Bluetooth, USB หรือ QZ Tray

## แอป Android
- GitHub Actions สร้าง APK ให้อัตโนมัติทุกครั้งที่แก้โฟลเดอร์ `android/` หรือกดรันเองที่แท็บ Actions → Android APK
- ตัวแอปเปิดหน้าเว็บนี้แบบเต็มจอผ่าน Chrome (Trusted Web Activity) แก้หน้าเว็บแล้วแอปอัปเดตตามทันที ไม่ต้องสร้าง APK ใหม่
- APK เซ็นด้วยกุญแจใน Secret `KEYSTORE_B64` / `KEYSTORE_PASSWORD` ไฟล์ตัวจริงเก็บไว้นอก repo **ห้ามทำหาย** ถ้าหายจะอัปเดตทับแอปเดิมไม่ได้
