# pospos247

ระบบ POS หน้าร้านบน GitHub Pages ข้อมูลทั้งหมด (สินค้า พนักงาน กะ บิล และแจ้งเตือน Telegram) อยู่ใน Google Apps Script ตัวเดิม

| หน้า | ลิงก์ |
|---|---|
| เวอร์ชันเดิม | https://alekryker.github.io/pospos/ |
| เวอร์ชันใหม่ (v2) | https://alekryker.github.io/pospos/v2/ |
| ทดลองเล่น (ไม่ใช้ข้อมูลจริง) | https://alekryker.github.io/pospos/v2/?demo=1 |

## v2 มีอะไรใหม่
- ออกแบบสำหรับมือถือ: แตะสินค้าเพื่อเพิ่ม ปุ่ม − บนการ์ด ตะกร้าเลื่อนขึ้นจากด้านล่าง เมนูอยู่ด้านล่าง
- บนคอมพิวเตอร์/แท็บเล็ตแนวนอน: สินค้าอยู่ซ้าย บิลอยู่ขวา
- ชำระเงินด้วย 4 วิธีเหมือนเดิม (เงินสด / QR / โอน / บัตร) มีปุ่มกดตัวเลข ปุ่มเงินด่วน และแสดงเงินทอนตัวใหญ่
- ใช้ API ชุดเดิมทั้งหมด: บัญชีพนักงาน กะ บิลพัก ยกเลิกบิล รายงาน และการจัดการสินค้า/พนักงาน จึงไม่ต้องแก้ Apps Script
- บิลที่พักไว้และการล็อกอินเดิมยังอยู่ (เก็บในเครื่องด้วยคีย์ชุดเดิม)

## เครื่องพิมพ์ (ตั้งค่า → เครื่องพิมพ์ใบเสร็จ)
| วิธี | ใช้กับ | หมายเหตุ |
|---|---|---|
| **Bluetooth** | Chrome บน Android และคอมพิวเตอร์ | เครื่องพิมพ์ความร้อนแบบ BLE ทั่วไป ภาษาไทยออกครบเพราะส่งเป็นภาพ สั่งเปิดลิ้นชักได้ |
| **สาย USB** | Chrome บน Android (สาย OTG) และคอมพิวเตอร์ | สั่งเปิดลิ้นชักได้ |
| **QZ Tray** | Windows / Mac | ต้องติดตั้งโปรแกรม QZ Tray ก่อน สั่งเปิดลิ้นชักได้ |
| **หน้าต่างพิมพ์** | ทุกเครื่อง รวมถึง iPhone (AirPrint) | เลือกเครื่องพิมพ์จากหน้าต่างของระบบ |

- เลือกขนาดกระดาษ 58 หรือ 80 มม. ได้
- ใส่ชื่อร้าน ที่อยู่ และข้อความท้ายบิลบนใบเสร็จได้ (ค่านี้บันทึกแยกในแต่ละเครื่อง)
- iPhone ใช้ Bluetooth ผ่านเว็บไม่ได้ เพราะ Safari ไม่รองรับ ให้ใช้ "หน้าต่างพิมพ์"
- เครื่องพิมพ์ Bluetooth รุ่นเก่าแบบ Classic (SPP) ใช้ผ่านเว็บไม่ได้ ให้ใช้สาย USB หรือแอปพิมพ์ของเครื่องนั้นแทน
